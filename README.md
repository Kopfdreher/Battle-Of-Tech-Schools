# MTSSSS Turborepo

This repository is a Turborepo with:

- `apps/web`: React frontend (Vite)
- `apps/api`: NestJS backend
- `packages/ui`: shared React UI package (default Turborepo package)
- `packages/eslint-config`: shared lint config package (default Turborepo package)
- `packages/typescript-config`: shared TypeScript config package (default Turborepo package)

## Install

```sh
npm install
```

## Run

```sh
npm run dev
```

## Build

```sh
npm run build
```

## Lint

```sh
npm run lint
```

## Type-check

```sh
npm run check-types
```
